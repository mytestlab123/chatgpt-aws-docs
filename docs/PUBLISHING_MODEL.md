# Documentation Publishing Model

This repository contains selected learning material from a separate implementation repository.

## Two-repository model

```text
implementation repository
        -> review selected learning content
        -> documentation repository
        -> GitHub Pages
```

Only intentionally selected documentation should be copied here.

## Recommended workflow

Phase 1: review and copy approved learning documents manually.

Phase 2: automate the copy with a narrowly scoped GitHub identity that can update this repository.

## Repository creation lesson

For a dedicated documentation repository, an empty repository is simplest. A starter template is also usable, but its placeholder project files should be initialized or removed before the site is considered complete.
